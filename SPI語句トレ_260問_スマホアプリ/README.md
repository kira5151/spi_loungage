# SPI 語句トレ（1問1答）

送られた教材写真から、**頻出語句210問**（p.192〜197）と**複数の意味50問**（p.206〜207）の合計260問を学習できるスマホ対応Webアプリです。

## 使い方

1. 問題を見て、頭の中で答えます。
2. 「答えを見る」で答えまたは解答例を確認します。
3. 「覚えた！」または「もう一度」を押します。
4. 「学習モード」を「要復習だけ」にすると、最後に「もう一度」と答えた問題だけを出題します。

「頻出語句210問」「複数の意味50問」を別々に選ぶこともできます。「未学習だけ」「ランダム出題」や、検索できる問題一覧もあります。学習状況は端末のブラウザに保存され、サーバーには送信しません。

## iPhoneのホーム画面に追加する方法

このアプリは公開URLからSafariで開いたときに、ホーム画面に追加できます。アプリのファイルを**同じ場所に**置いてHTTPSのWebサーバーから配信してください（インストールは不要）。

GitHub Pagesを使用する例：

1. GitHubに新しいリポジトリを作成します。
2. このフォルダにある `index.html`、`app.js`、`data.js`、`style.css`、`manifest.webmanifest`、`sw.js`、`icon-180.png`、`icon-192.png`、`icon-512.png` をリポジトリの最上位にアップロードします。
3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を選びます。
4. 表示された公開URLをiPhoneのSafariで開きます。
5. Safariの **共有 → ホーム画面に追加** を選択します。

**ご注意：** GitHub Pagesで公開すると教材由来の語句・例文・解説も他人から見られる可能性があります。教材の権利と利用条件を確認し、個人的な学習の範囲で取り扱ってください。公開したくない場合は、自分だけがアクセスできるWebサーバーに置くか、付属の単一HTMLファイルを使用してください。

## パソコンでの利用

`index.html` を開いて利用できます。環境によってはローカルファイルへのブラウザ制限があるため、その場合はこのフォルダで `python -m http.server 8000` を実行して `http://localhost:8000` にアクセスしてください。

## ファイル内容

- `index.html`：アプリ画面
- `app.js`：学習・復習・保存処理
- `data.js`：問題データ260問
- `style.css`：画面デザイン
- `manifest.webmanifest`、`sw.js`、`icon-*.png`：ホーム画面追加・オフライン対応
- `vocab.tsv`、`multiple.tsv`：問題データ編集用原稿

iPhoneのホーム画面に追加したアプリでは、初回オンラインアクセス後に画面・問題データをキャッシュし、オフライン利用に対応します。ただしSafariでWebサイトデータを削除すると、記録も消えることがあります。別の端末との同期機能はありません。
